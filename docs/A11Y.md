# دسترسی‌پذیری نیکسو

مرکز تنظیمات: Settings → دسترسی‌پذیری (`/app/settings/accessibility`). API همگام‌سازی دستگاه/حساب: `GET/POST /api/a11y`. میانبرها جایگزین Authentication نیستند.

## Preferenceها

- کاهش حرکت (و `prefers-reduced-motion` سیستم)
- کنتراست بالا / کاهش شفافیت / زیرخط لینک
- اندازه متن ۱۰۰–۱۷۵٪ (Zoom مرورگر هم پشتیبانی می‌شود)
- اهداف لمسی حداقل ۴۴px
- اعلان Screen Reader (خاموش / مؤدبانه / همه)
- میانبر صفحه‌کلید و هشدار پایان نشست
- همگام با حساب پس از Login؛ کوکی `nixo_a11y` برای دستگاه مهمان (Secret نیست)

## میانبرها

Alt+Shift+/ فهرست. Alt+Shift+F جستجو. Alt+1…4 ناوبری. Escape بستن پنل. Ctrl+Enter ارسال. میانبرهای مرورگر (Ctrl+T/N/W/…) ثبت نمی‌شوند.

## Chat و تماس

پیام‌ها `article` با نام شامل فرستنده، زمان، وضعیت، پاسخ و پیوست هستند. متن کاربر ترجمه نمی‌شود. ایموجی‌تنها برچسب دارند. Live Region برای پیام جدید و Typing. کنترل تماس Label و `aria-pressed` دارد.

## فرم و مودال

Error با `role=alert` و `aria-describedby`. Dialog با نام، Escape، و بازگردانی Focus. جستجو Dialog با اعلام تعداد نتیجه.

## تست

`src/lib/a11y.test.ts` در CI (`npm test`): Contrast، Shortcut reserved، Markup audit، نام پیام، Persistence Preference.

## Workflow زبان

برچسب‌های دسترسی با Locale و `dir` صفحه هماهنگ‌اند. RTL ترتیب Tab منطقی را از Direction سند می‌گیرد.
