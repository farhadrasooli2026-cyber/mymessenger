# هوش مصنوعی نیکسو

لایهٔ AI مستقل است: Provider Abstraction، مدیریت مدل، Fallback، صف، Rate Limit، سقف مصرف، اعتبار، هزینه، حریم، رضایت، و کنترل ادمین. اگر AI خاموش یا Down شود، ورود، پیام، تماس و فایل کار می‌کنند.

## کجا

- کاربر: `/app/ai` و Settings → هوش مصنوعی (`/app/settings/ai`)
- ادمین: `/app/admin` زبانهٔ هوش مصنوعی (`/api/ai/ops`) با `ai.view` / `ai.manage`
- API کاربر: `GET/POST /api/ai` و `POST /api/nixo-ai`

## قوانین سخت

- AI پنهانی به پیام، فایل، صوت تماس یا دادهٔ خصوصی دیگران دسترسی ندارد.
- کلید Provider هرگز به کلاینت نمی‌رود. `GEMINI_API_KEY` یا `OPENAI_API_KEY` فقط در env سرور است.
- رمز، توکن، کلید خصوصی و دادهٔ پرداخت وارد Prompt نمی‌شود (حذف می‌شود).
- AI به‌تنهایی حساب را حذف یا مسدود دائم نمی‌کند؛ Moderation کمکی است و بررسی انسانی لازم است.
- محتوای تولیدشده به‌عنوان AI مشخص است.
- قابلیت‌ها Kill، Monitor و Rollback دارند.
- همان Access Control پیام‌رسانی اعمال می‌شود (جستجو فقط `collectSearchHits`).

## Provider و مدل

پاسخ‌های Nixo AI از مدل زنده می‌آیند: **Google Gemini 1.5 Flash** اگر `GEMINI_API_KEY` ست باشد، وگرنه **OpenAI GPT-4o-mini** با `OPENAI_API_KEY`. مسیر `POST /api/nixo-ai` پرامپت را می‌گیرد و متن مدل را برمی‌گرداند. اگر کلید نباشد یا شبکه/مدل شکست بخورد، پیام خطا این است: «ارتباط با Nixo AI برقرار نشد. لطفاً تنظیمات API Key را بررسی کنید.» موتور داخلی `local` فقط در تست واحد (Vitest بدون کلید) برای ایمنی و ذخیرهٔ چت استفاده می‌شود و به کاربر محصول به‌عنوان پاسخ چت برنمی‌گردد. مدل‌های Fast / Balanced / Advanced نسخه‌دارند. پرامپت‌های مهم `pv-1` / `pv-0` هستند؛ Rollback به `pv-0` می‌رود.

## حریم و جداسازی

متن قبل از مدل Sanitize می‌شود. Ciphertext، ضبط تماس، و ادعای «پیام خصوصی دیگری» رد می‌شوند. Embedding فقط برای کاربر مالک ایندکس می‌شود. Cache کلیدش شامل `userId` است.

## مصرف

سقف روزانه از Entitlement (`ai.plus`). Rate Limit روزانه. سقف توکن/Context/پاسخ در Policy. اعتبار داخلی اختیاری با Idempotency تا دوبار هزینه نشود. سقف هزینهٔ مدل در ops.

## ارزیابی

دکمهٔ Evaluation روی دیتاست داخلی دود (ترجمه، رد ناامن، عدم ادعای حقیقت). آزمایش A/B فقط برچسب کنترل‌شده است؛ ایمنی یکی است.
