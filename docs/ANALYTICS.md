# تحلیل و هوش تجاری نیکسو

لایهٔ محصول (`/api/bi`، زبانهٔ **تحلیل**) جدا از پایش عملیاتی (`/api/monitor`، زبانهٔ **پایش**) است.

## قوانین

- ابزار نظارت مخفی روی کاربر نیست.
- رمز، Access/Refresh Token، API Key، کلید خصوصی، Secret، OTP، ciphertext و متن پیام وارد تحلیل نمی‌شوند.
- سوژهٔ رویداد `HMAC(bi:userId)` است نه شناسهٔ حساب.
- رضایت محصول پیش‌فرض خاموش است (Settings → مرکز حریم خصوصی). Opt-out رویداد اختیاری را حذف می‌کند.
- رویداد ضروری امنیت/پایداری/عملیات (ورود ناموفق، قیف ثبت‌نام) جدا از رضایت محصول است و همچنان بدون PII است.
- شکست لوله، ورود، پیام، تماس، آپلود یا دانلود را متوقف نمی‌کند (صف ناهمگام؛ خطا بلعیده می‌شود).
- داشبورد RBAC: `analytics.view` / `analytics.manage`. متریک پایداری و امنیت تجمیعی نیازمند `monitor` است.
- دسترسی تحلیل محتوای خصوصی پیام، فایل یا تماس را باز نمی‌کند.

## لوله

1. `trackBi` اعتبارسنجی نام/نسخهٔ schema / props
2. Dedup با `nonce`
3. صف حافظه + flush غیرمسدود
4. Raw تا ۷ روز (سقف ۴۰۰۰)
5. Daily aggregate تا ۹۰ روز
6. حذف با `purge` یا پاک‌سازی حساب

رویداد کلاینت فقط `ui.session_start`، `ui.feature_open`، `ui.onboarding_step` با allowlist ویژگی.

## داشبوردها

Admin / Product / Growth / Engagement / Reliability / Security / Storage / Call / Search / Business.

بازه `24h|7d|30d`، مقایسه با بازهٔ قبل، فیلتر کشور/زبان/دستگاه/OS.

## آزمایش

گروه control/treatment با درصد. متریک موفقیت اجباری است. Rollback وضعیت را `rolled_back` می‌کند و variant برنمی‌گرداند. آزمایش مجوز امنیتی نمی‌دهد.

## هزینه

برآورد Storage / Bandwidth از حجم Store و بایت پایش. فاکتور واقعی نیست. کلید third-party در داشبورد نیست.
