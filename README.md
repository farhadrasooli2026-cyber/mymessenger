# NIXO نیکسو

پیام‌رسان و پلتفرم ارتباطی نسل جدید.

**NIXO Connect. Exchange. Beyond Borders.**  
اتصال، تبادل و ارتباط بدون مرز.

نیکسو کپی واتساپ یا تلگرام نیست. هویت آن روی حریم خصوصی، امنیت لایه‌لایه، اتصال، سرعت، سادگی، طراحی مدرن، پایداری و ارتباط جهانی است. حرف **X** یعنی Connection، Exchange، Cross-border و Next — دو مسیر که به هم می‌رسند.

## این نسخه

برش قابل استفاده:

1. ثبت‌نام با موبایل یا ایمیل و تأیید کد سمت سرور
2. ساخت پروفایل: نام، نام خانوادگی، نام کاربری یکتا، بیو، عکس (دوربین / گالری / مجموعه نیکسو)، حریم خصوصی و پیش‌نمایش
3. ویرایش بعدی از تنظیمات → پروفایل
4. گفتگوی خصوصی داخل نیکسو: ارسال و مدیریت پیام، مسدودسازی، گزارش (Spam / Abuse / Fake Account / Harassment / Other)
5. ظاهر: پس‌زمینه برنامه و چت، تم روشن/تیره/سیستم، اندازه متن و حباب پیام
6. امنیت چت: پیام‌ها روی دستگاه با AES-GCM رمز می‌شوند؛ سرور فقط پاکت (`ciphertext` + `nonce`) را نگه می‌دارد و متن را نمی‌پذیرد. کلید نخ در مرورگر می‌ماند. کلید عمومی هویت برای معماری بعدی ثبت می‌شود. احراز هویت و محدودیت Block سمت سرور است.

7. پیام صوتی: نگه داشتن میکروفون، قفل، موج صدا، پخش، حذف، هدایت، View Once
8. رسانه و فایل: گالری نیکسو با دسته عکس/ویدیو/GIF/صوت/سند/فایل/لینک، آلبوم، انتخاب چندتایی، Recently Deleted، قفل گالری، Storage Manager و Cache جدا از فایل دائمی. در چت: دوربین جلو/عقب/Flash، گالری دستگاه و نیکسو، فایل، پیش‌نمایش ویرایش (چرخش، نقاشی، متن، استیکر، Trim/Mute ویدیو)، کیفیت استاندارد/بالا/اصلی، فشرده‌سازی، Uploading با درصد و لغو/تلاش دوباره. View Once و انقضا. دسترسی فایل با نشست و توکن منقضی؛ چت E2EE روی دستگاه. محدودیت Forward طبق حریم؛ نیکسو اسکرین‌شات همهٔ دستگاه‌ها را تضمین نمی‌کند. Settings → Data & Storage → Media.
9. View Once و پیام‌های ناپدیدشونده: دو قابلیت جدا. View Once برای عکس، ویدیو و صوت فقط یک مشاهده/پخش است؛ هدایت، ذخیره، دانلود و بازپخش محدود می‌شود. پیام ناپدیدشونده در سطح گفتگو با زمان‌های ۱۰ث / ۳۰ث / ۱د / ۱س / ۱روز / ۱هفته / سفارشی؛ متن از ارسال، رسانه از مشاهده. سرور با ساعت خودش انقضا را اعمال می‌کند و ciphertext را پاک می‌کند. پشتیبان معمولی پیام منقضی یا یک‌بارمصرف را برنمی‌گرداند. ثبت صفحه تا حد امکانات وب/سیستم‌عامل محدود می‌شود؛ نیکسو ادعا نمی‌کند عکس گرفتن با دستگاه دیگر را ۱۰۰٪ متوقف می‌کند.
10. تماس صوتی و تصویری از چت (Voice Call / Video Call)، صفحه ورودی با نام، عکس، Accept/Decline/Cancel، تماس دوم (پذیرش / رد / قطع فعلی و پذیرش)، Mute/Unmute، Camera On/Off، تعویض جلو/عقب، خروجی صدا (بلندگو / گوشی / بلوتوث / هدفون در صورت پشتیبانی دستگاه)، اشتراک صفحه و Stop Sharing، PiP، ادامه در پس‌زمینه نیکسو با کوچک‌کردن، کیفیت خودکار/کم‌مصرف/بالا، نمایش اتصال ضعیف و Reconnecting. Signaling فقط با نشست و مالکیت Call ID؛ دانستن شناسه تماس برای Join یا ارسال SDP کافی نیست. سابقه Incoming / Outgoing / Missed / Declined / Cancel با Caller، تاریخ، ساعت، مدت، نوع و وضعیت. حریم Everyone / Contacts / Nobody / Selected، مسدودسازی، محدودیت تماس ناشناس، اعلان ورودی/ازدست‌رفته/گروهی، ضد سیلاب سمت سرور. سیگنال روی سرور است؛ رسانه با WebRTC روی دستگاه حلقه می‌شود با Echo Cancellation / Noise Suppression / AGC در صورت پشتیبانی مرورگر (E2EE معماری دستگاه؛ سرور محتوا را برای پردازش غیرضروری نمی‌گیرد). ضبط تماس فعال نیست و اگر اضافه شود اطلاع و رضایت لازم است. NIXO جایگزین تماس اضطراری سیستم‌عامل نیست.
11. گروه‌ها: ساخت (اعضا → نام/عکس/توضیح → عضویت)، نقش Owner/Admin/Moderator/Member، مجوز سمت سرور، افزودن عضو (مخاطب، نام کاربری، لینک دعوت، QR)، درخواست عضویت، Mute/Restrict/Ban/Remove، چند پین، پاسخ و منشن، واکنش، نظرسنجی، جستجو و رسانهٔ مشترک، بی‌صدا کردن اعلان، پس‌زمینهٔ محلی، قوانین و خوشامدگویی، پیام‌های سیستمی، ترک، حذف سه‌مرحله‌ای، گزارش، ضد سیلاب. متن گروه E2EE است؛ ظرفیت اعضا از تنظیمات گروه تا سقف زیرساخت قابل مدیریت است.
12. جامعه‌ها: فضای مرکزی برای چند گروه مرتبط و کانال‌های اطلاع‌رسانی داخل جامعه. نقش Owner/Admin/Moderator/Member، دعوت (لینک، QR، نام کاربری، مخاطب)، درخواست عضویت، اطلاعیه، مجوز سمت سرور، Mute/Restrict/Ban/Remove، جستجو، رسانه، اعلان (همه / منشن / مهم / بی‌صدا)، گزارش، ضد سیلاب، ترک و حذف سه‌مرحله‌ای. پست کانال جامعه برای اعضا روی سرور است؛ گفتگوی گروه همچنان E2EE.
13. کانال‌ها: ساخت Name → Photo (گالری/دوربین/نیکسو) → Description → Privacy. عمومی با @username یکتا در Search؛ خصوصی فقط لینک/دعوت. Subscribe/Unsubscribe، پست متن/عکس/ویدیو/GIF/فایل/لینک/صوت/نظرسنجی/کوییز/آلبوم، Draft و زمان‌بندی، Edited، حذف و چند پین، واکنش و نظر با مجوز، گروه بحث، هدایت و محدودیت کپی (بدون ادعای اسکرین‌شات)، اعلان On/Mute/مهم، چند ادمین با Permission سمت سرور (پست، ویرایش، حذف، پین، اعضا، نظر، دعوت، ربات، AI)، انتقال مالکیت با تأیید TRANSFER، حذف سه‌مرحله‌ای، آمار بازدید/واکنش/نظر/هدایت، Live و Live Chat، استوری ۲۴ساعته کانال، Audit، گزارش پست/کانال، ضد سیلاب. نشان Verified از سرور است و جعل‌پذیر از فرانت نیست. پست روی سرور است تا همهٔ مشترک‌ها ببینند.
14. استوری و وضعیت: ویزارد Create Story → نوع (عکس/ویدیو/متن/GIF/استیکر/موقعیت) → Edit (برش، چرخش، متن با قلم/اندازه/چینش/جایگاه، نقاشی، استیکر داخلی، فیلتر، محو، موسیقی مجاز نیکسو، لینک، منشن) → Privacy → Post. دوربین جلو/عقب و گالری، فشرده‌سازی، Uploading/Retry، پیش‌نویس. انقضای ۲۴ساعته، آرشیو فقط صاحب، Everyone / مخاطبین / Close Friends / انتخاب‌شده / Hide From، Mute/Unmute، حلقهٔ پروفایل دیده‌نشده/دیده‌شده، نوار پیشرفت با مکث و ورق چپ/راست. واکنش، پاسخ در صندوق استوری با اعلان (متن داخل پاکت E2EE چت تزریق نمی‌شود)، اشتراک با اجازه، گزارش، Block. رسانه با نشست + توکن امضاشده و انقضا سرو می‌شود؛ فرانت استوری خصوصی را دور نمی‌زند. استوری کسب‌وکار و کانال. آمار بازدید/reach/واکنش/پاسخ برای صاحب. وضعیت کوتاه جدا از Online/Last Seen. نیکسو ادعا نمی‌کند اسکرین‌شات را در همهٔ دستگاه‌ها غیرممکن کند.
15. جستجو و پیام‌های ذخیره‌شده: جستجوی سراسری کاربران، نام کاربری، گروه، کانال، جامعه، پست‌های عمومی مجاز، رسانه و لینک با فیلتر نوع/فرستنده/تاریخ، صفحه‌بندی و محدودیت ضد سوءاستفاده. متن گفتگوی خصوصی فقط روی دستگاه (E2EE) جستجو می‌شود. تاریخچهٔ جستجو با پاک‌کردن. Saved Messages و Bookmark خصوصی همان حساب (نه در Search عمومی) با تگ، پوشه، پین، سطل ۱۴روزه، و جستجوی متن/فایل/نوع/تاریخ/چت.
16. حریم خصوصی: داشبورد Settings → Privacy با Checkup. شماره، پیدا شدن با شماره، ایمیل (پیش‌فرض هیچ‌کس)، عکس، بیو، آخرین بازدید، آنلاین، رسید خواندن، Typing، ضبط صوت، پیام، تماس، گروه، جامعه، کانال، استوری، مسدود، مخاطب با هش، موقعیت، محدودیت هدایت/ذخیره/اشتراک، درخواست حذف. همه روی سرور اعمال می‌شوند. ظاهر پروفایل برای دیگران نیست. نیکسو ادعا نمی‌کند اسکرین‌شات با دستگاه دیگر را ۱۰۰٪ متوقف کند.
17. امنیت حساب و E2EE: داشبورد Settings → Security. پیام، صوت، عکس، ویدیو و فایل خصوصی قبل از ارسال با AES-GCM روی دستگاه رمز می‌شوند؛ سرور ciphertext می‌بیند نه متن. تماس حلقهٔ WebRTC روی دستگاه است. کلید خصوصی روی سرور ذخیره نمی‌شود؛ هر مرورگر/دستگاه کلید نخ خودش را دارد. دستگاه جدید نشست جدا می‌گیرد و بدون تأیید وارد محتوای قبلی نمی‌شود. فهرست دستگاه‌ها با خروج/ابطال سمت سرور. رمز دومرحله‌ای (رمز هش‌شده + OTP). Passkey در صورت پشتیبانی مرورگر. هشدار ورود جدید، نشست و توکن قابل انقضا و ابطال، OTP هش‌شده با سقف تلاش، ضد brute-force، مجوز API سمت سرور. پشتیبان E2EE فقط تأییدگر HMAC. گزارش آسیب‌پذیری از همین داشبورد. نیکسو ادعا نمی‌کند غیرقابل هک است.
18. ماندگاری حساب و Backup: حساب به‌خاطر inactivity حذف نمی‌شود. حذف فقط از Settings → Account با هشدار، OTP، تأیید نهایی و Cancel؛ سپس ۱۴ روز Pending Deletion و امکان لغو با ورود. پس از مهلت، داده‌های قابل حذف پاک می‌شوند و خلاصهٔ امنیتی می‌ماند. چند دستگاه و همگام پروفایل/گروه/کانال/تنظیمات. پشتیبان رمزشده روی دستگاه (رمز + Recovery Key هش‌شده؛ سرور پاکت AES-GCM). Auto/دستی، زمان‌بندی، انتخاب رسانه، Restore روی دستگاه احرازشده، حذف پشتیبان، و اعلام خطا. تغییر شماره/ایمیل با تأیید. Log Out All Devices.
19. دستگاه‌ها و بازیابی: Settings → Devices با نام، نوع، OS، نسخه، آخرین فعالیت، موقعیت تقریبی، Active/Inactive، This Device، Trusted و Unknown. ورود دستگاه جدید اطلاع و تأیید از دستگاه مورد اعتماد می‌خواهد و تا آن زمان به E2EE دسترسی ندارد. Log Out / Remove / Log Out All Other Devices نشست را باطل می‌کند. بازیابی از /recover با OTP (+ رمز دومرحله‌ای در صورت فعال بودن) Verification را دور نمی‌زند؛ بعد از موفقیت نشست‌های دیگر باطل و Checkup باز می‌شود. Recovery Code یک‌بارمصرف.
20. ربات‌ها و پلتفرم Bot: ساخت با نام، @username یکتا، توضیح، عکس، دسته (Utility/Games/Education/Business/Productivity/Entertainment/Support). وضعیت Active / Disabled / Suspended / Deleted. توکن `nxtb_` فقط یک‌بار، Rotate/Revoke، هرگز در لاگ یا خطای عمومی. Bot API نسخهٔ **v1** (`/api/bot/v1`) با Bearer، Rate Limit، Quota، Idempotency-Key، Reply/Edit/Delete فقط پیام خود ربات، Callback سمت سرور (دکمه از پیام همان گفتگو)، Storage جدا per-bot، Job زمان‌بندی‌شده با سقف (کد شخص ثالث روی هستهٔ نیکسو اجرا نمی‌شود). Webhook فقط HTTPS + HMAC، صف Retry و Timeout ۸ث. Directory و جستجو در `/app/bots`. Connected Bots در Settings → Privacy & Security → Connected Bots. نظر/امتیاز با فیلتر هرزنامه. Version/Rollback در داشبورد. مجوز پیش‌فرض به چت E2EE، مخاطبین، گالری، میکروفون، دوربین و موقعیت ممکن نیست. OTP و نشست کاربر به ربات داده نمی‌شود. پرداخت فقط NIXO Pay (هنوز فعال نیست). Mini App همان سندباکس بخش ۳۹. تغییر User ID / Bot ID / Message ID دسترسی غیرمجاز نمی‌دهد.

35. Mini Apps & Web Apps: Directory در `/app/apps` با دسته، جستجو، پروفایل، امتیاز و نظر. اجرا فقط در iframe سندباکس (`allow-scripts` بدون same-origin) با CSP و `connect-src 'none'`؛ API فقط از والد با نشست نیکسو. مجوز کمینه (پروفایل، نام کاربری، اطلاعات پایه، مخاطب، دوربین، میکروفون، موقعیت، فایل انتخابی، اعلان، پرداخت) با Prompt و لغو از Settings → Privacy & Security → Connected Apps. توکن محدود، منقضی و قابل ابطال؛ با Logout همهٔ دستگاه‌ها و Disconnect باطل می‌شود. Verification فقط سرور. Web App فقط HTTPS؛ Redirect خارج از دامنهٔ ثبت‌شده رد می‌شود. پرداخت کارت به App داده نمی‌شود. وضعیت Active / Maintenance / Suspended / Removed. Developer Dashboard برای Create/Update/Review/آمار کلی بدون دادهٔ خصوصی کاربر. تغییر User ID یا App ID دسترسی حساب دیگر نمی‌دهد.
21. هوش مصنوعی: NIXO AI داخل برنامه (گفتگوی اختصاصی، موضوع‌های جدا، زمینهٔ همان چت). ترجمهٔ فارسی/انگلیسی/ترکی، خلاصه، نوشتن و اصلاح متن. ابزار Rewrite/Translate/Improve و پیشنهاد پاسخ روی دستگاه است تا متن E2EE بدون رضایت به سرور نرود. Voice با Speech API مرورگر در صورت پشتیبانی. تصویر SVG محلی؛ OCR/فایل متنی. کمک Admin فقط با چسباندن متن و سوییچ Data Controls. سقف روزانه، Stop/Regenerate/Copy/Save/بازخورد، ایمنی و شفافیت: آموزش از گفتگوی تو انجام نمی‌شود. Settings → AI.
22. کسب‌وکار: تبدیل همین حساب (نه ورود جدا) به Business با نام، دسته، لوگو، توضیح، تماس، ساعات، موقعیت و @username یکتا. پروفایل با Open/Closed، نقشه، Message/Call/Website/Email. صندوق مشتری (Unread/Read/Important/Archived/Spam/Customers)، برچسب، پاسخ آماده، Welcome/Auto/Away. چند ادمین با مجوز سمت سرور. کاتالوگ کالا و خدمت، جستجو، سبد، سفارش و وضعیت. ربات و کانال قابل اتصال. AI کمکی. استوری از حساب مالک. تأیید Verified فقط پس از بررسی مدارک نیکسو (قابل خرید نیست). گزارش کلاهبرداری. آمار. پرداخت رسمی هنوز فعال نیست. Settings → Business.
23. فروشگاه و پرداخت: Shop روی Business با ارز، ارسال (Standard/Express/Pickup)، واریانت، موجودی، تخفیف و کوپن. Checkout با آدرس، روش ارسال و پرداخت. قیمت، تخفیف و کارمزد فقط روی سرور. شناسه NIXO-ORDER-، وضعیت پرداخت جدا از ارسال. Invoice و رسید. سندباکس NIXO Pay و Wallet بدون ذخیرهٔ شماره کارت؛ Webhook با HMAC. Idempotency و جلوگیری از قیمت جعلی. Refund، لغو طبق قانون فروشگاه، اختلاف، تسویه و تاریخچه تراکنش. Profile → Orders و Settings → Shop.
24. جستجو و نام کاربری: Search مرکزی با فیلتر People/Groups/Channels/Bots/Communities/Messages، دسته‌بندی نتایج، پیشنهاد، تاریخچه با حذف تکی و Clear Search History، صفحه‌بندی، رتبه‌بندی Exact Match. پیدا شدن با Username/Phone/Email طبق حریم Everyone/Contacts/Nobody/استثنا روی سرور. متن چت خصوصی E2EE ایندکس نمی‌شود. فهرست دو حرفی کاربران بسته است. نشان ✓ فقط از سرور. Username یکتا با قوانین طول/نویسه، نام‌های رزرو، نگهداری نام قبلی پس از تغییر (دسترسی با نام قدیم ساخته نمی‌شود)، بررسی لحظه‌ای Available/Taken/Invalid و محدودیت نرخ. Deep link `/u/username`. NIXO AI همان ایندکس مجاز را می‌بیند.
25. اعلان‌ها: Notification Center با دسته، Mark as Read / Mark All / حذف / Clear All، نشان خوانده‌نشده. Settings → Notifications برای Preview، Lock Screen (Full / Sender / Hidden)، صدا، لرزش، Badge، DND با زمان و استثنا، و سوییچ Messages/Groups/Channels/Calls/Stories/Bots/Business/AI/Payments/Security. Mute چت/گروه/کانال/ربات (۱س / ۸س / ۱روز / ۱هفته / تا روشن کردن). اعلان امنیت (ورود، دستگاه جدید، رمز، بازیابی) DND را دور می‌زند. متن E2EE در Push نیست. محدودیت نرخ ضد اسپم. Push مرورگر اختیاری است و شکست آن وضعیت جعلی نمی‌سازد.
26. تماس گروهی: Voice/Video از گروه، سقف شرکت‌کننده سمت سرور (پیش‌فرض ۸، حداکثر ۱۶)، افزودن/حذف/Mute شرکت‌کننده توسط Host/Admin، لینک Join Call فقط با ورود و عضویت گروه، مجوز میکروفون/دوربین مرورگر. دستکاری کلاینت برای ورود به تماس خصوصی دیگران کافی نیست؛ عضویت و توکن روی سرور چک می‌شود.
27. موسیقی و صوت: پخش‌کننده داخلی با Mini/Full Player، Play/Pause/Prev/Next/Seek/Volume، Shuffle/Repeat، Queue قابل مرتب‌سازی، پلی‌لیست، Favorites، Recently Played، Continue Listening، Sleep Timer، سرعت ۰٫۵ تا ۲ برابر. کتابخانه Music/Songs/Podcasts/Voice/Files با جستجو و فیلتر. کاتالوگ فقط تن‌های اصل نیکسو با مجوز داخلی است — موسیقی تجاری بدون مجوز عرضه نمی‌شود. فایل شخصی با AES-GCM روی دیسک و توکن منقضی؛ تغییر URL برای دیگری کافی نیست. Voice چت E2EE با موج، سرعت، ضبط Pause/Resume/Cancel، هدایت و View Once. Settings → Voice & Audio. ادعای قفل کامل Lock Screen فقط در مرورگرهایی است که Media Session دارند.
28. مخاطبین و افراد: دفترچهٔ خصوصی با جستجو، Favorite، دسته (خانواده/دوستان/کار/سفارشی)، برچسب، یادداشت رمزشده، نام و عکس محلی (عکس پروفایل طرف را عوض نمی‌کند). مخاطبین گوشی فقط با Contact Picker و مجوز سیستم‌عامل (Allow / Limited / Deny) و Sync قابل خاموش. کشف شماره/ایمیل با پاسخ یکسان وقتی حساب نیست یا حریم پنهان است؛ محدودیت نرخ. Username یکتا. دعوت با لینک منقضی و سقف استفاده و Share دستگاه. QR فقط username. پروفایل طبق حریم، گروه‌های مشترک فقط اگر هر دو عضو باشند، بدون لیست مخاطبین دیگران. Block/Unblock/گزارش، درخواست ارتباط، پیشنهاد فقط با اجازهٔ پیدا شدن. Import/Export، تشخیص تکراری و Merge با تأیید، تداخل چنددستگاه. حذف مخاطب حساب نیکسو را پاک نمی‌کند. مجوز مشاهده سمت سرور است.
29. پوشه‌ها و سازمان‌دهی چت: فهرست گفتگو بر اساس آخرین فعالیت با نشان خوانده‌نشده، منشن و پیش‌نویس. Pin (سقف ۸) بالای لیست، Archive/Unarchive و Archived Chats، قانون برگشت با پیام جدید، Mute با ۱س/۸س/۱روز/۱هفته/تا روشن کردن، Mark Read/Unread، حذف محلی بدون پاک کردن حساب طرف، Clear با تأیید، جستجو داخل چت و بین پوشه‌ها. پوشه‌های آماده All/Unread/Personal/Groups/Channels/Bots/Business/Favorites/Archived و پوشهٔ سفارشی با نام، آیکون، Include/Exclude. حذف پوشه چت را پاک نمی‌کند. مرتب‌سازی Recent/Unread/Name/Favorites، یادداشت و برچسب خصوصی، Favorite/Priority، انتخاب چندتایی و Swipe. پیش‌نمایش لیست طبق حریم؛ متن E2EE خام نیست. پوشه فقط برای صاحب حساب است؛ دستکاری Folder ID یا Chat ID دسترسی دیگری نمی‌دهد. Settings → Chats → Chat Organization. کش فهرست با شناسهٔ حساب جدا می‌شود و با Logout پاک می‌گردد.
30. Saved Messages و Bookmarks: صندوق خصوصی برای متن، عکس، ویدیو، صوت، Voice، فایل، لینک، مخاطب، موقعیت و استیکر. Unsave پیام اصلی چت را پاک نمی‌کند. ارجاع به پیام اصلی فقط با Permission؛ اگر اصل حذف شده باشد Saved آن را برنمی‌گرداند. Bookmark با دسته Work/Personal/Important/Later و پوشهٔ سفارشی. Note و Tag خصوصی، Favorite، Pin، مرتب‌سازی، Media/Files/Links جدا، پیش‌نمایش لینک بدون اجرای محتوا، پخش رسانه با URL امضاشده و منقضی. سطل ۱۴روزه، حذف دائمی، Delete All با تأیید، Export/Backup/Restore، گزارش، محدودیت نرخ. تغییر Saved ID دسترسی حساب دیگر نمی‌دهد. ذخیره مالکیت محتوا را منتقل نمی‌کند.
31. Reactions, Stickers & Emoji: ایموجی استاندارد دستگاه (فونت هر OS فرق دارد)، پنل انتخاب با دسته و جستجو، اخیر و Favorite. واکنش روی پیام خصوصی/گروه/کانال با شمارنده، تغییر/حذف واکنش خود، چند کاربر، حریم نام واکنش‌دهنده، تنظیم مجاز و خاموش‌کردن توسط ادمین. استیکر در Pack، افزودن/حذف Pack بدون پاک شدن مالکیت سازنده، Favorite/Recent، جستجو و پیشنهاد، استاتیک و پویا با سقف فرمت امن، Preview قبل از ارسال، آپلود PNG/WEBP با بررسی نوع/حجم/امضا/ابعاد، بستهٔ خصوصی و لینک عمومی، گزارش و moderation. اعلان واکنش بدون لو رفتن محتوا روی Lock Screen اگر Hide باشد. همگام چنددستگاه روی سرور. URL فایل موقت و نشست‌دار. Settings → Stickers & Emoji. مجوزها سمت سرورند؛ تغییر Message ID یا URL برای واکنش روی پیام دیگری کافی نیست.

32. Voice Messages: ضبط با نگه‌داشتن/قفل، Pause/Resume/Cancel/Preview/Send، سقف و کف مدت سمت سرور، Opus/WebM فشرده، موج صدا، Seek، Volume، سرعت ۰٫۵ تا ۲، پخش پشت‌سرهم و Auto Play طبق تنظیم، دانلود دستی و خودکار (Wi-Fi / Mobile / Never) با محدودیت Data Saver، پخش آفلاین فایل دانلودشده، Reply/Forward/Share/Save/Bookmark/Favorite، جستجوی رسانه، وضعیت Sending/Sent/Delivered/Failed با Retry محدود و لغو آپلود، مجوز میکروفون سیستم‌عامل، توقف امن هنگام تماس ورودی یا خروج از چت، مسیر پخش بلندگو/گوشی/هدفون/بلوتوث در صورت پشتیبانی، کنترل Lock Screen با Media Session در مرورگرهای پشتیبان، اعتبارسنجی فایل کانال با امضا نه پسوند، E2EE در چت خصوصی و گروه (سرور ciphertext می‌بیند)، View Once و ناپدیدشونده، حذف برای من/همه، Rate Limit و ضد تکرار Retry، همگام تنظیمات چنددستگاه. Settings → Voice & Audio. تغییر Message ID یا URL برای شنیدن Voice دیگری کافی نیست.

33. Files & Documents: انتخاب چند فایل، پیش‌نمایش امن PDF/عکس/ویدیو/صوت بدون اجرای فایل خطرناک، سقف حجم سمت سرور، آپلود تکه‌تکه با درصد و لغو/ادامه/Retry، دانلود تکه‌تکه با درصد و لغو/Retry، تغییر نام محلی بدون تغییر نام سرور، Auto Download (Wi-Fi / Mobile / Never) و Data Saver، جستجو بر اساس نام/نوع/حجم/تاریخ/چت و مرتب‌سازی، Recent Files، Saved Messages، Forward/Share/Reply. فایل چت خصوصی و گروه E2EE و تکه‌تکه است؛ فایل کانال با امضای باینری، Zip Bomb و Path Traversal در آرشیو، جداسازی پوشهٔ کاربر، URL نشست‌دار و Rate Limit. ادمین گروه می‌تواند sendFiles، سقف حجم و فهرست پسوند اعلام‌شده را محدود کند (نوع واقعی فایل E2EE برای سرور قابل اسکن نیست). Settings → Files & Storage. تغییر File ID یا URL برای فایل دیگری کافی نیست.

34. Live Streaming: ساخت Live با عنوان، توضیح، تصویر، Public/Private/Members/Invite، زمان‌بندی، Reminder، سقف بیننده، Audio Only، کیفیت Auto/Low/Medium/High، چت با Slow Mode، واکنش، Host/Co-Host/Guest، Kick/Mute/Ban، Recording/Replay با همان حریم، Discovery و Trending فقط برای Live عمومی، آمار بدون شناسهٔ بیننده. رسانه روی دستگاه میزبان حلقه می‌شود؛ سرور سیگنال، حضور و مجوز را نگه می‌دارد نه پیکسل CDN. لینک دعوت بدون نشست معتبر کار نمی‌کند. Settings → Live. تغییر Live ID یا URL برای دیدن پخش خصوصی دیگری کافی نیست.

همگام‌سازی کلید چنددستگاهی در بخش جداگانه کامل می‌شود.

مدیر پس‌زمینه‌ها: `/admin/backgrounds`

نیکسو ادعا نمی‌کند هرگز قابل نفوذ نیست. امنیت از ابتدا با Security by Design، Privacy by Design، Zero Trust، Least Privilege، احراز هویت امن، رمزنگاری سرتاسری و زیرساخت امن طراحی می‌شود.
