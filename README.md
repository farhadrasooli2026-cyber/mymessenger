# NIXO — ثبت‌نام امن

سیستم ثبت‌نام NIXO با دو مسیر **موبایل** و **ایمیل**. مسیر اجباری است:

**شناسه → کد تأیید سمت سرور → تکمیل پروفایل → حساب فعال**

گزینه Skip برای مرحله تأیید وجود ندارد. شماره یا ایمیل تأییدنشده هرگز به حساب فعال تبدیل نمی‌شود.

## اجرای محلی

```bash
npm install
cp .env.example .env.local
npm run dev
```

برنامه روی `http://127.0.0.1:43151` اجرا می‌شود.

```bash
npm test
npm run lint
```

## قوانین تأیید

- کد ۶ رقمی، یک‌بارمصرف، و با انقضای ۳ دقیقه
- ارسال مجدد با فاصله حداقل ۴۵ ثانیه؛ کد قبلی باطل می‌شود
- حداکثر ۳ ارسال به هر شناسه در ۱۵ دقیقه و ۸ ارسال در ساعت برای هر IP
- حداکثر ۵ تلاش برای هر کد؛ پس از آن کد باطل می‌شود
- قفل موقت شناسه بعد از چند چرخه شکست
- مقایسه کد با `scrypt` و salt جداگانه؛ کد خام در پایگاه‌داده ذخیره نمی‌شود
- شناسه با HMAC ذخیره می‌شود و مقدار واقعی بعد از تأیید با AES-256-GCM رمز می‌شود

## ضد سوءاستفاده

| تهدید | کنترل |
| --- | --- |
| Brute force | سقف تلاش، قفل، هش کند OTP |
| Spam / OTP abuse | سقف ارسال، cooldown، قفل شناسه |
| Rate-limit bypass | محدودیت همزمان روی IP و شناسه |
| Automated registration | honeypot + چالش زمانی «من ربات نیستم» |
| Account enumeration | پاسخ یکسان برای ارسال کد؛ وجود حساب فقط بعد از اثبات مالکیت |

صندوق آزمایشی پیام فقط با کوکی همان نشست و وقتی `NIXO_DEMO_INBOX` روشن باشد کار می‌کند. در تولید آن را `false` کنید و ارسال واقعی پیامک/ایمیل را جایگزین کنید.
