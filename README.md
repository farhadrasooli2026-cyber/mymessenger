# NIXO نیکسو

پیام‌رسان و پلتفرم ارتباطی نسل جدید.

**NIXO Connect. Exchange. Beyond Borders.**  
اتصال، تبادل و ارتباط بدون مرز.

نیکسو کپی واتساپ یا تلگرام نیست. هویت آن روی حریم خصوصی، امنیت لایه‌لایه، اتصال، سرعت، سادگی، طراحی مدرن، پایداری و ارتباط جهانی است. حرف **X** یعنی Connection، Exchange، Cross-border و Next — دو مسیر که به هم می‌رسند.

**مستندات:** داخل برنامه [`/docs`](/docs) (جستجو + فهرست). فایل‌های Git در [`docs/README.md`](docs/README.md). نصب: [`docs/INSTALL.md`](docs/INSTALL.md). معرفی محصول: [`/about`](/about).

ورود از `/` فقط کارت Login نئونی (تأیید با کد یا رمز) است؛ مطالب معرفی به `/about` منتقل شده‌اند.

## اجرا

```bash
npm install
npm run dev
```

سرور توسعه روی `http://127.0.0.1:43151` بالا می‌آید.

## این نسخه

برش قابل استفاده:

1. ثبت‌نام با موبایل یا ایمیل و تأیید کد سمت سرور
2. ساخت پروفایل: نام، نام خانوادگی، نام کاربری یکتا، بیو، عکس (دوربین / گالری / مجموعه نیکسو)، حریم خصوصی و پیش‌نمایش
3. ویرایش بعدی از تنظیمات → پروفایل
4. گفتگوی خصوصی داخل نیکسو: ارسال و مدیریت پیام، مسدودسازی، گزارش (Spam / Abuse / Fake Account / Harassment / Other)
5. ظاهر: پس‌زمینه برنامه و چت، تم روشن/تیره/سیستم، اندازه متن و حباب پیام. فایل‌های استاتیک: لوگوی `/Nixo-logo.png` در ورود، اسپلش، هدر چت و About؛ آواتارهای `/avatars/`؛ پس‌زمینه‌های `/backgrounds/` با گالری، شفافیت و تاری زنده در Appearance → Chat Background. آپلود عکس پروفایل و پس‌زمینه همچنان ذخیرهٔ محلی/سرویس حساب است.
6. امنیت چت: پیام‌ها روی دستگاه با AES-GCM رمز می‌شوند؛ سرور فقط پاکت (`ciphertext` + `nonce`) را نگه می‌دارد و متن را نمی‌پذیرد. کلید نخ در مرورگر می‌ماند. کلید عمومی هویت برای معماری بعدی ثبت می‌شود. احراز هویت و محدودیت Block سمت سرور است.
6b. قابلیت‌های اختصاصی نیکسو: هدایت بدون نام، ترجمه داخل حباب، ارسال زمان‌بندی‌شده و بی‌صدا، حالت روح، تب‌های شخصی/گروه/کانال/ربات/برگزیده، پخش ۰٫۵×–۲×، شیشه و پس‌زمینه public، ISO 639-1، ذخیره انرژی، تفکیک داده و ذخیره گالری، پاک‌سازی اختیاری «اگر دوری». Settings → قابلیت‌های نیکسو.

7. پیام صوتی: نگه داشتن میکروفون، قفل، موج صدا، پخش، حذف، هدایت، View Once
8. رسانه و فایل: گالری نیکسو با دسته عکس/ویدیو/GIF/صوت/سند/فایل/لینک، آلبوم، انتخاب چندتایی، Recently Deleted، قفل گالری، Storage Manager و Cache جدا از فایل دائمی. در چت: دوربین جلو/عقب/Flash، گالری دستگاه و نیکسو، فایل، پیش‌نمایش ویرایش (چرخش، نقاشی، متن، استیکر، Trim/Mute ویدیو)، کیفیت استاندارد/بالا/اصلی، فشرده‌سازی، Uploading با درصد و لغو/تلاش دوباره و Resume تکه‌تکه. View Once و انقضا. **File ID یا URL به‌تنهایی دسترسی نمی‌دهد**؛ دانلود، پیش‌نمایش، گالری و جستجو فقط با نشست + عضویت/مالکیت سمت سرور. گالری با HMAC و انقضای کوتاه؛ چت E2EE تکه‌رمزشده در پوشهٔ خصوصی نه Public Directory. محدودیت حجم جدا برای عکس/صوت/سند/ویدیو، امضای باینری، رد اجرایی، حذف EXIF/GPS روی آپلود گالری، صف پردازش پس‌زمینه با Retry محدود، پاک‌سازی آپلود ناقص و فایل یتیم. محدودیت Forward طبق حریم؛ نیکسو اسکرین‌شات همهٔ دستگاه‌ها را تضمین نمی‌کند. Settings → Data & Storage → Media.
9. View Once و پیام‌های ناپدیدشونده: دو قابلیت جدا. View Once برای عکس، ویدیو و صوت فقط یک مشاهده/پخش است؛ هدایت، ذخیره، دانلود و بازپخش محدود می‌شود. پیام ناپدیدشونده در سطح گفتگو با زمان‌های ۱۰ث / ۳۰ث / ۱د / ۱س / ۱روز / ۱هفته / سفارشی؛ متن از ارسال، رسانه از مشاهده. سرور با ساعت خودش انقضا را اعمال می‌کند و ciphertext را پاک می‌کند. پشتیبان معمولی پیام منقضی یا یک‌بارمصرف را برنمی‌گرداند. ثبت صفحه تا حد امکانات وب/سیستم‌عامل محدود می‌شود؛ نیکسو ادعا نمی‌کند عکس گرفتن با دستگاه دیگر را ۱۰۰٪ متوقف می‌کند.
10. تماس صوتی و تصویری از چت (Voice Call / Video Call) و تماس گروهی. Incoming / Outgoing با Accept، Decline، End، Cancel؛ Missed در سابقه و به‌صورت پیام سیستم در Chat. وضعیت Calling / Ringing / Connecting / Connected / Reconnecting / Ended / Failed / Missed / Declined. کیفیت شبکه (RTT / Loss / Jitter)، اتصال ضعیف و تلاش مجدد ICE. Mute، Camera، Speaker، Switch Camera، Screen Share با اجازهٔ مرورگر، Bluetooth/Headset در صورت پشتیبانی دستگاه. Adaptive bitrate و Frame Rate. Signaling و ICE (STUN؛ TURN اختیاری از env سرور) فقط با نشست احرازشده؛ Call ID / URL / Token در لاگ عمومی نمی‌آید. لینک Join Call توکن + انقضا دارد و فقط عضو واردشدهٔ گروه Join می‌شود. سابقه قابل پاک‌کردن برای همان حساب. حریم Everyone / Contacts / Nobody / Selected، Block، Report تماس. ضبط تماس عمداً خاموش است و API ضبط رد می‌شود. رسانه روی دستگاه حلقه می‌شود (Echo Cancellation / Noise Suppression / AGC مرورگر). E2EE تماس در این برش معماری حلقهٔ محلی است نه Relayed P2P کامل بین دو دستگاه جدا. NIXO جایگزین تماس اضطراری سیستم‌عامل نیست.
11. گروه‌ها: ساخت (اعضا → نام/عکس/توضیح → عضویت)، نقش Owner/Admin/Moderator/Member و نقش سفارشی، مجوز سمت سرور، افزودن عضو (مخاطب، نام کاربری، لینک دعوت، QR)، درخواست عضویت با انقضا، Mute/Restrict/Ban موقت و دائم/Unban/Remove، چند پین، پاسخ و منشن، واکنش، نظرسنجی، جستجو و رسانهٔ مشترک با کنترل دسترسی، بی‌صدا کردن اعلان، پس‌زمینهٔ محلی، قوانین و خوشامدگویی، پیام‌های سیستمی، ترک، حذف سه‌مرحله‌ای، گزارش گروه/عضو/پیام، ضد سیلاب و لینک. متن گروه E2EE است؛ ظرفیت اعضا از تنظیمات گروه تا سقف زیرساخت قابل مدیریت است.
75. Groups System: شناسهٔ تصادفی، مالکیت سرور، Public/Private، Username یکتا، لینک دعوت با Token/انقضا/سقف/ابطال، Join Request (Pending/Approved/Rejected/Cancelled/Expired)، Self-Join فقط برای گروه عمومی طبق سیاست، وضعیت عضویت Active/Left/Removed/Banned، فهرست اعضا با جستجو و Pagination و حریم، سقف اعضا، ماتریس مجوز شامل پیام/رسانه/فایل/لینک/استیکر/منشن/واکنش، سلسله‌مراتب نقش، تنظیمات تاریخچهٔ عضو جدید، حذف و پین با Authorization، اعلان Join/Invite/Mention/Reply، Welcome و Rules، Rate Limit، Audit ادمین. تغییر Group/Member/Role/Invite/Message ID دسترسی خصوصی نمی‌دهد.
76. Channels System: شناسهٔ تصادفی کانال و پست، مالک سمت سرور، Name/Description با اعتبارسنجی، آواتار با MIME/حجم/ابعاد و EXIF-strip، Public با @username یکتا و Discovery/Search/Recommendation فقط برای کانال عمومی، Private فقط مشترک/دعوت/درخواست. لینک دعوت با Token تصادفی، انقضا، سقف استفاده و Revoke بدون دور زدن مجوز. اشتراک با ID و وضعیت Active/Pending/Left/Banned، Join Request با Approve/Reject/انقضا، فهرست مشترک با Pagination و حریم، سقف مشترک، Ban/Unban روی همهٔ APIها. نقش Owner/Admin/Editor/Moderator و نقش سفارشی با ماتریس مجوز و سلسله‌مراتب. پست متن/رسانه با اعتبارسنجی، زمان‌بندی و Retry Broadcast، پین، واکنش قابل خاموش کردن، نظر با Rate Limit و گزارش، گروه بحث، هدایت با Attribution و محدودیت کپی، اعلان/Mute/Silent/منشن، هشتگ در جستجوی عمومی، آمار بازدید Unique، رشد مشترک، Audit، حذف با DELETE. تغییر Channel/Subscriber/Role/Post/Invite ID دسترسی خصوصی نمی‌دهد.
77. Calls & Voice System: Call ID و Session ID تصادفی، تماس ۱:۱ و گروهی، وضعیت شرکت‌کننده (Invited/Ringing/Connecting/Connected/Muted/Disconnected/Declined/Missed/Removed). شروع فقط با Authorization، Block و حریم Everyone/Contacts/Friends/Nobody/Selected سمت سرور؛ تماس با خود رد می‌شود. Incoming/Outgoing، Accept/Decline/Cancel، Timeout به Missed، Busy، End با مدت و زمان شروع/پایان. سابقه فقط صاحب حساب با Pagination. اعلان با Ringtone/Vibration/Silent. WebRTC Signaling احرازشده، SDP/ICE اعتبارسنجی، STUN و TURN با اعتبار کوتاه‌عمر HMAC. توکن رسانه و توکن اتاق گروهی کوتاه‌عمر (۱۵ دقیقه) و پس از پایان/Kick باطل. Reconnect با سقف و Timeout، Recover، Mute محلی و وضعیت Mute طرف مقابل، انتقال دستگاه (Handoff) با توکن جدید. اتاق گروهی با Host، انتقال Host، Invite، لینک با انقضا/ابطال، سقف شرکت‌کننده. ضبط تماس خاموش و نیازمند رضایت. Rate Limit زنگ، محدودیت موقت سوءاستفاده، گزارش تماس (`targetKind: call`) فقط برای شرکت‌کننده. تغییر Call/Session/Participant/Room/Token ID Audio دیگری را نمی‌دهد.
78. Video Calls & Media: روی همان زیرساخت تماس. Camera Start/Stop بدون قطع تماس، Front/Rear و انتخاب دوربین، Preview محلی، Local/Remote Tile، Avatar وقتی دوربین خاموش است. اگر Camera رد شود Voice Fallback. کیفیت Adaptive، Freeze Detection، Retry Video، Speaker/Grid و Active Speaker در تماس گروهی. Screen Share با اجازهٔ سیستم‌عامل، Indicator، و در صورت پشتیبانی System Audio. Signaling/SDP/ICE/STUN/TURN/SRTP همان مدل امن بخش ۷۷. Host نمی‌تواند دوربین دیگری را روشن کند. ضبط همچنان Consent-only و API رد می‌شود. تغییر Call/Session/Stream/Token ID تصویر خصوصی دیگری را نمی‌دهد.
12. جامعه‌ها: فضای مرکزی برای چند گروه مرتبط و کانال‌های اطلاع‌رسانی داخل جامعه. نقش Owner/Admin/Moderator/Member، دعوت (لینک، QR، نام کاربری، مخاطب)، درخواست عضویت، اطلاعیه، مجوز سمت سرور، Mute/Restrict/Ban/Remove، جستجو، رسانه، اعلان (همه / منشن / مهم / بی‌صدا)، گزارش، ضد سیلاب، ترک و حذف سه‌مرحله‌ای. پست کانال جامعه برای اعضا روی سرور است؛ گفتگوی گروه همچنان E2EE.
13. کانال‌ها و Broadcasting: ساخت Name → Photo → Description → Privacy. عمومی با @username یکتا در Search/Discovery/Trending؛ خصوصی با لینک دعوت (انقضا و سقف استفاده) یا Join Request. وضعیت Active / Restricted / Suspended / Deleted سمت سرور. Subscribe/Unsubscribe، Mute اعلان با مدت، پست متن/عکس/ویدیو/صوت/Voice/فایل/لینک/نظرسنجی/کوییز/آلبوم با اعتبارسنجی نوع و حجم، Caption، ویرایش/حذف، صف زمان‌بندی و لغو، Broadcast با صف دسته‌ای، Retry محدود و Idempotency برای مشترک‌ها. نقش Owner/Admin/Editor/Moderator و نقش سفارشی. چند پین، واکنش با حریم، نظر و Reply با Moderation، گروه بحث، Repost/Forward با محدودیت مالک. بازدید Unique جدا از تکرار، آمار بدون افشای لیست خصوصی، خروجی فراداده برای مالک. انتقال مالکیت TRANSFER، حذف با تأیید DELETE. SSE احرازشده `/api/channels/:id/live`؛ تغییر Channel/Post/Role/Subscriber/Room ID دسترسی نمی‌دهد. نشان Verified و Restrict/Suspend اضطراری فقط ایمنی نیکسو. پست روی سرور است تا همهٔ مشترک‌ها ببینند.
14. استوری و وضعیت: ویزارد Create Story → نوع (عکس/ویدیو/صوت/متن/GIF/استیکر/موقعیت) → Preview/Edit → Privacy (Everyone/Contacts/Friends/Close Friends/Selected/Nobody + Hide From) → Draft/Post. انقضای ۲۴ساعته، آرشیو فقط صاحب با Restore، Highlights، Mute (حلقه در فید اصلی مخفی)، Seen/Unseen، Pause/Resume/Mute صوت. واکنش قابل خاموش شدن، پاسخ با Rate Limit، منشن فقط اگر مخاطب اجازهٔ دیدن استوری را داشته باشد. لینک Share با توکن منقضی که حریم را دور نمی‌زند. Discovery فقط استوری Everyone. رسانه Signed URL و Cache خصوصی؛ حذف/انقضا توکن و رسانه را باطل می‌کند. تغییر Story/Viewer/Media/Highlight/Token ID استوری خصوصی دیگری را باز نمی‌کند.
14b. صفحهٔ Updates: تب Status و Channels با هدر Updates، منوی سه‌نقطه (انتخاب/ساخت کانال، حریم استوری، Ad preferences)، کاروسل استوری (Add status، حلقهٔ سبز ندیده‌شده، Viewer با Reply و واکنش)، دوربین و متن استوری، فهرست کانال‌های دنبال‌شده با پیش‌نمایش/زمان/نشان نخوانده و Explore.
49. Stories & Status (کامل): شناسه تصادفی، مالکیت سرور، صف پردازش، Thumbnail، Pagination، Prefetch، گزارش فقط Viewer مجاز، Block، Rate Limit انتشار/بازدید/پاسخ/واکنش/منشن/آپلود، ضد تکرار، Audit، هایلایت با Authorization جدا، Completion Rate، پاک‌سازی رسانهٔ منقضی.
79. Stories & Status System: Story ID تصادفی، Owner سمت سرور، Text/Image/Video/Audio/Media با اعتبارسنجی طول/MIME/حجم، پردازش و Thumbnail، Preview قبل از Publish، انقضای خودکار و حفاظت Expired، حریم Everyone/Friends/Contacts/Close Friends/Custom/Excluded، Viewer Authorization، فهرست بیننده فقط صاحب بدون شناسهٔ اضافی، شمارش بدون تکرار، ناوبری و Progress، Reply/Reaction/Mention با مجوز، Share/Forward بدون افشای خصوصی، لینک توکن‌دار، Delete/Edit قبل از انقضا، Archive/Restore، Highlight با Cover و حریم، اعلان و Mute، Discovery و Search بدون نشت خصوصی، Feed مرتب و صفحه‌بندی، حلقه Seen/Unseen، Preload کنترل‌شده، Signed URL کوتاه‌عمر، Revoke رسانه، Report/Block/Moderation/Rate Limit، Authentication و IDOR Protection.
80. Notifications System: شناسه و Event ID تصادفی، تولید سمت سرور با Validation رویداد و Recipient. مرکز اعلان با Pagination، Read/Unread، Mark All، Badge همگام، Grouping و Idempotency. Push چنددستگاه با توکن رمزشده، Rotation، Revoke با دستگاه، صف Pending/Queued/Sent/Delivered/Failed/Expired، Retry با Backoff و Dead Letter، Provider nixo-web/nixo-local. اولویت تماس و امنیت، Silent، صدا/لرزش/Preview/Lock Screen. تنظیم دسته Message/Group/Channel/Story/Call/Friend/Mention/Reaction/Reply؛ Mute مدت‌دار؛ Quiet Hours با استثنای تماس و Security Alert. Deep Link و Quick Reply دوباره Authorization می‌شوند؛ پاسخ E2EE از اعلان تزریق نمی‌شود. Payload بدون رمز/نشست/کلید. حذف همگانی هشدار امنیتی خوانده‌نشده را نگه می‌دارد. جستجو فقط اعلان خود کاربر. Audit و متریک تحویل. تغییر Notification/Device/Token ID اعلان دیگری را نمی‌دهد.
81. Search & Discovery System: موتور جستجوی مرکزی با Query Validation/Sanitization، حداقل ۲ نویسه، سقف ۲۰۰، Debounce و Rate Limit. Tabهای All/Users/Friends/Groups/Channels/Messages/Media/Posts/Stories به‌علاوه فیلترهای موجود. Relevance، Exact/Partial/Prefix، Fuzzy، Typo، Boolean AND/OR/NOT، Autocomplete. نتایج فقط پس از Authentication، Authorization، Block، Membership، Subscription و Ban. User خصوصی، گروه/کانال دعوت‌محور، پیام E2EE، استوری غیرعمومی و رسانهٔ خصوصی از Global Search، Suggestions، Discovery، Hashtag، Username، Cache عمومی و ایندکس عمومی استخراج نمی‌شوند. Friends فقط از فهرست دوست با حریم Username. استوری Everyone زنده در ایندکس عمومی؛ Delete/Expire/تغییر حریم ایندکس را به‌روز می‌کند. تاریخچهٔ جستجو خصوصی با Clear. Popular/Trending فقط هشتگ و محتوای عمومی — نه Query خصوصی. Discovery با تنوع نوع، تازگی و محبوبیت مجاز. متریک Query/Result/Latency/P95/P99/Error/Zero-result. Rebuild و Partial Reindex و Tombstone. Enumeration دو حرفی و IDOR روی open مسدود است. جزئیات [`docs/SEARCH.md`](docs/SEARCH.md).

Mute مدت‌دار، XSS روی متن پست/نظر، Link Preview بدون واکشی مقصد، گزارش کانال خصوصی فقط برای مشترک. حذف با DELETE. تغییر Channel ID / Post ID / Role ID / Subscriber ID / Room ID دسترسی نمی‌دهد.

41. اعلان و Push: سیستم مرکزی با شناسه و Event ID یکتا، مالکیت سرور و Idempotency. نوع Message/Reply/Mention/Reaction/Friend/Follow/Story/Group Invite/Join/Channel/Call/Missed/Security/System. اولویت Normal/High/Critical. صف Worker با Retry محدود، Exponential Backoff، Failover بین nixo-web و nixo-local، Dead Letter، Rate Limit، Collapse و Throttle. توکن چنددستگاه با نشست معتبر؛ دستگاه فعلی مشخص است؛ endpoint کامل در API نیست. Deep Link فقط `GET /api/notify/open?id=` پس از مالکیت و مجوز منبع. Quiet Hours با Time Zone. متریک صف و Delivery. تغییر Notification ID دسترسی اعلان دیگری نمی‌دهد. اعلان امنیت سیاست نیکسو را دور نمی‌زند.

42. جستجو و Discovery: ایندکس فقط محتوای عمومی (User قابل کشف، گروه/کانال Public، پست منتشرشدهٔ کانال عمومی، بستهٔ استیکر رسمی/عمومی). همگام با صف Idempotent و Retry. Cursor Pagination، Highlight، Debounce، Cache با ابطال نسل ایندکس. Deep Link `GET /api/search/open?id=` پس از Authorization. پیشنهاد Discovery قابل Hide. Query اعتبارسنجی، عملگر امن، Rate Limit، Enumeration دو حرفی بسته، XSS روی snippet. فارسی/انگلیسی/ترکی با Normalization و Transliteration. خرابی جستجو بقیهٔ نیکسو را متوقف نمی‌کند.
43. Contacts & User Management: شناسهٔ غیرقابل حدس، پروفایل، Username یکتا، Avatar، Bio، Last Seen/Online طبق حریم، دفترچه مستقل، Friend/Follow/Block/Mute/Report، Sync با Permission، Matching بدون افشای شماره، Import/Export فقط دادهٔ خود کاربر، Audit روی Block و Privacy.
44. مرکز حریم خصوصی و امنیت: Settings → Privacy Center (`/app/settings/privacy-center`) با امتیاز امنیت، Checkup حریم، تغییر رمز (هش، تأیید رمز فعلی، سیاست حداقل ۱۰ نویسه)، Authenticator TOTP با تأیید کد، Backup Code یک‌بارمصرف، نشست و Refresh Token هش‌شده با چرخش و ابطال، دستگاه جدید و هشدار، تاریخچه ورود، Mute/Block/Restrict، رضایت داده با تاریخچه، خروجی JSON با توکن HMAC منقضی و یک‌بارمصرف فقط برای صاحب حساب، حذف حساب با OTP و مهلت ۱۴روز. CSP، هدر امنیتی، CORS فقط همان Host، کوکی HttpOnly/SameSite، بررسی Origin روی POST حساس، Rate Limit روی ۲FA/خروجی. رسانه همچنان با نشست و URL امضاشده. Secret فقط از env (`NIXO_PEPPER` / `NIXO_DATA_KEY` / `NIXO_SESSION_SECRET`). تغییر User ID یا Export Token حساب دیگری را باز نمی‌کند.
45. Media & File Storage: Vault مرکزی در `/app/storage` و Settings → Storage. شناسه و Storage Key تصادفی، مالکیت User/Group/Channel سمت سرور، آپلود تکه‌ای با نشست منقضی و Resume، اعتبارسنجی MIME/پسوند/جادو، رد HTML/SVG/اجرایی، Path Traversal و Zip Bomb، نام تصادفی روی دیسک و Original Name در متادیتا، فضای خصوصی خارج از Public، Signed URL با انقضا و Generation برای ابطال، Range/Resume دانلود، Hash و Dedup، EXIFزدایی JPEG، Thumbnail، صف پردازش با Retry و Idempotency، قرنطینه فایل مشکوک، سهمیه User/Group/Channel، گالری/جستجو/سطل نرم و حذف دائمی، GC یتیم، پشتیبان رمزشدهٔ متادیتا، Cache-Control خصوصی، Content-Disposition و nosniff. گالری و چت E2EE قبلی دست‌نخورده‌اند. تغییر File ID یا URL فایل دیگری را نمی‌دهد.
46. تماس صوتی و تصویری (مرکز تماس): `/app/calls` و Settings → Calls. Voice / Video / Group Voice / Group Video با Call ID تصادفی، وضعیت Calling/Ringing/Connecting/Connected/Reconnecting/Ended/Rejected/Missed/Failed، Incoming و Outgoing، Accept/Reject/Cancel/End، Missed با اعلان. سابقه فقط برای صاحب حساب با جستجو، فیلتر Incoming/Outgoing/Missed/نوع، صفحه‌بندی Cursor و حذف. Who can call شامل Everyone/Contacts/Friends/Nobody/Selected؛ Mute تماس را مسدود نمی‌کند، Block روی ساخت و Signaling اعمال می‌شود. مجوز سمت سرور و IDOR روی Call/Room/User ID. WebRTC با Offer/Answer/ICE، STUN، TURN با اعتبار زمان‌دار HMAC در صورت تنظیم env، اتاق جدا، Host و Remove، Active Speaker، کیفیت تطبیقی، Echo Cancellation / Noise Suppression / AGC مرورگر، Reconnect با سقف، پاک‌سازی اتاق و سیگنال کهنه، Ringtone و Vibration در کلاینت وب، اعلان Incoming/Missed، TLS/WSS برای Signaling، Rate Limit و ضد سیلاب. ضبط تماس خاموش است (۴۰۳ + رضایت لازم اگر بعداً روشن شود). متریک در `/api/calls/metrics` و داشبورد مرکز تماس بدون SDP و بدون توکن. منطقه `NIXO_CALL_REGION`. تغییر Call ID / Room ID / Signaling Data تماس دیگری را باز نمی‌کند.
47. گروه و کانال: مرکز `/app/spaces` و Settings → Spaces. ساخت عمومی/خصوصی با نام، توضیح، آواتار، Username یکتا در برابر کاربر/گروه/کانال و نام‌های رزرو. Owner با انتقال TRANSFER. عضو و مشترک با شناسهٔ رابطه. Join/Leave، Discovery فقط برای فضای عمومی، Invite با توکن/انقضا/سقف/ابطال، Join Request با Approve/Reject/Cancel. نقش Owner/Admin/Moderator/Editor و نقش سفارشی؛ مجوز Send/Delete/Ban/Add/Invite/Manage/Edit Info/Manage Admins سمت سرور. Ban موقت/دائم، Restrict، Promote/Demote با حفاظت Owner. پیام گروه E2EE با ویرایش ۱۵دقیقهٔ فرستنده، Idempotency، تاریخچه از زمان عضویت، Forward طبق تنظیم گروه. پست کانال با Draft/Schedule/Silent/Announcement، Reply/Reaction/Pin، آمار بازدید بدون افشای لیست خصوصی. Mute، جستجو و صفحه‌بندی اعضا با مرتب‌سازی نام/نقش. ضد سیلاب Join/Invite/Message/Post. گزارش محتوا با `channelId:postId` / `groupId:messageId`. تغییر Group/Channel/Member/Invite/Message/Role ID دسترسی یا نقش مدیریتی نمی‌دهد.

همگام‌سازی کلید چنددستگاهی در بخش جداگانه کامل می‌شود.

مدیر پس‌زمینه‌ها: `/admin/backgrounds`

نیکسو ادعا نمی‌کند هرگز قابل نفوذ نیست. امنیت از ابتدا با Security by Design، Privacy by Design، Zero Trust، Least Privilege، احراز هویت امن، رمزنگاری سرتاسری و زیرساخت امن طراحی می‌شود.
